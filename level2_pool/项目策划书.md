# 二级 IP 池（子 IP 池 / 站点级）项目策划书

## 1. 项目概述

二级池是**站点级**的 IP 池：一个站点一个独立进程（单站点独立进程），负责从一级池同步 IP、对目标站点做连通性测试、并按需把可用 IP 租赁给用户。

- 同步：首次全量拉取，之后每 3 秒按 id 增量拉取；增量返回空时全量重拉并重置水位线
- 入池测试：经代理真实访问目标站点，延迟 < 2000ms 才入池（通用站点默认测 `www.baidu.com`）
- 租赁：获取即标记（无过期时间），支持释放/删除/全部释放
- 复验：每 60 秒对池内全部 IP 做「代理可达性」测试（`proxy_reachability_test`，不测出口），删除不通过者

## 2. 项目定位与边界

**只做**：一级池增量同步 → 站点连通测试 → 入池 → 租赁分配/释放/删除 → 周期复验 → 对外 API。
**不做**：供应商拉取（一级池）、按站点路由分发（代理层）。

**对外依赖**：一级池 HTTP API（网络）；`ip_pool_common`（公共库）。
**被依赖**：代理层通过本服务 HTTP API 透传请求（进程级解耦）。

## 7. 核心模块设计

### 7.1 syncer.py —— 增量同步（含空响应重置）

```python
class Level1SyncClient:
    def __init__(self, base_url: str, session: aiohttp.ClientSession): ...
    async def fetch_all(self) -> list[IpRecord]          # GET /api/v1/ips
    async def fetch_after(self, id_: int) -> list[IpRecord]  # GET /api/v1/ips/after/{id}

class SyncTask:
    last_synced_id: int | None = None
    async def _sync_once(self):
        if self.last_synced_id is None:
            batch = await self.client.fetch_all()        # 首次全量
        else:
            batch = await self.client.fetch_after(self.last_synced_id)
            if not batch:                                # 空响应 → 一级池可能重启
                batch = await self.client.fetch_all()    # 重新全量拉取
        if batch:
            self.last_synced_id = max(r.id for r in batch)   # 水位线推进/重置
        passed = await self.tester.site_filter(batch)    # 站点测试 <2000ms
        for rec in passed:
            await self.pool.upsert(rec)
    async def run(self):                                  # 每 sync_interval(3s) 循环
```

**关键点（空响应重置）**：
- 增量返回空 → 判定一级池重启 → 全量重拉，`last_synced_id` 重置为该批最大 id。
- 重置后按代理身份（`proxy_url`）去重 upsert，**不移除**现存记录（空闲与租赁均保留），旧记录靠 60s 复验与 TTL 自然淘汰。
- 一级池 id 仅作水位线，由 syncer 内部维护，**不参与二级池记录身份**，彻底规避一级池重启后 id 空间重叠的冲突。

### 7.2 pool.py —— 租赁池

```python
class Level2Pool:
    def __init__(self):
        self._records: dict[str, Level2Record] = {}    # 唯一键 proxy_url(ip+port+protocol)
        self._order: list[str] = []                     # 入池顺序，最新在末尾
        self._id_index: dict[int, str] = {}             # 本地id → proxy_url
        self._next_id: int = 0
        self._lock = asyncio.Lock()

    async def upsert(self, rec: Level2Record):          # 存在则刷新(延迟/ttl/时间)，新则分配本地id
    async def acquire(self) -> Level2Record | None:     # 最新→最旧遍历，取第一个空闲并标记租赁
    async def release(self, id_: int) -> bool           # 解除租赁标记
    async def remove(self, id_: int) -> bool            # 删除记录(含解除租赁)
    async def release_all(self) -> int                  # 解除全部租赁，返回数量
    def all(self) -> list[Level2Record]                 # 查询，不产生租赁标记
    def stats(self) -> PoolStats                        # 池内/租赁/空闲 按协议细分
    async def sweep_ttl(self, now: float) -> int        # TTL 淘汰(若支持)
```

**关键点**：
- 唯一键为 `proxy_url`（代理身份），本地 id 自增且不复用，供 API `release/delete/{id}` 精确引用。
- `acquire` 最新优先：从 `_order` 尾部向前扫描首个 `leased=False`，原子标记，百并发下经 `asyncio.Lock` 保证不重复分配。
- 租赁无过期时间，仅可被显式 `release/delete/release-all` 解除。

## 8. 核心流程

```
启动 → 创建 sync client/pool/tester → 启动 SyncTask/RevalidateTask/TtlSweeper
SyncTask 每3s: 增量(after/{id}) → 空则全量重置 → 站点测试<2000ms → upsert 入池
RevalidateTask 每60s: 全量 proxy_reachability_test → 失败者删除
TtlSweeper 每5s: 清扫 TTL 过期(若支持)
用户 acquire: 最新优先取空闲 → 标记租赁 → 返回 proxy_url
用户 release/delete/release-all: 解除/删除标记
关闭: 取消任务 → 关闭 session → 优雅退出
```

## 9. API 设计

基路径 `/api/v1`。

| 方法 | 路径 | 说明 | 返回 data 结构 |
|---|---|---|---|
| GET | `/status` | 运行状态 | `uptime,total_pulled,total_entered,api_call_count,last_synced_id,errors{sync_failures,test_failures,revalidate_failures,ttl_sweep_failures,empty_acquires},drops,pool_stats` |
| GET | `/count` | 计数 | `total,by_proto,leased_total,leased_by_proto,free_total,free_by_proto` |
| GET | `/ips` | 全部 IP（不标记） | `[{id,ip,port,protocol,proxy_url,latency_ms,leased,ttl,created_at}]` |
| POST | `/ips/acquire` | 获取 1 个空闲 IP 并租赁 | 单条记录或 `{code:40402}` 空池 |
| POST | `/ips/{id}/release` | 释放指定 IP | 释放结果 |
| DELETE | `/ips/{id}` | 删除指定 IP | 删除结果 |
| POST | `/ips/release-all` | 释放全部 | 释放数量 |

## 11. 鲁棒性与容错

- **同步异常隔离**：一级池故障/网络抖动不影响现有租赁；下次 tick 自动重试。
- **空响应重置**：一级池重启可无感恢复（全量重拉 + 水位线重置），且不误删现存记录。
- **并发安全**：池变更、租赁分配全部在 `asyncio.Lock` 下；`acquire` 原子，不重复分配同一 IP。
- **超时控制**：站点测试/复验/同步均设 aiohttp 超时。
- **空池处理**：无空闲 IP 时 `acquire` 返回明确错误码（非 500），调用方可重试。
- **优雅启停**：`lifespan` 统一管理任务生命周期。

## 12. 可扩展性

- 站点测试逻辑可注入（替换为其它站点验证策略）。
- 复验策略可替换（如仅 TTL 淘汰、或质量评分）。
- 阈值/周期全部配置化。
- 单站点独立进程：水平扩展只需为新站点复制一份配置并换端口，互不影响。
